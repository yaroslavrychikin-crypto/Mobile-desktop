# Kotlin: условные конструкции — конспект и практика

## 1. Обзор: какие условные конструкции есть в Kotlin

В отличие от Java/C, в Kotlin **нет тернарного оператора** `?:` в роли «if-выражения» (символ `?:` здесь занят оператором Элвиса). Вместо него `if` — это **выражение**, возвращающее значение.

Условные конструкции Kotlin:

| Конструкция | Назначение | Возвращает значение? |
|---|---|---|
| `if` / `else if` / `else` | ветвление | ✅ да (как выражение) |
| `when` | множественное ветвление (аналог `switch`) | ✅ да |
| `when` с subject | сравнение с одним объектом | ✅ да |
| `when` без subject | цепочка условий | ✅ да |
| `if` как выражение | замена тернарника | ✅ да |
| `?:` (Элвис) | значение по умолчанию для `null` | ✅ да |
| `takeIf` / `takeUnless` | условная передача значения | ✅ да |

Ключевая идея: **почти всё в Kotlin — выражение**, поэтому вместо «объяви переменную и присвой в ветках» пишут «присвой результат выражения».

## 2. `if` / `else if` / `else` — классическое ветвление

### 2.1. Базовый синтаксис

```kotlin
fun main() {
    val temperature = 25

    // Скобки вокруг условия обязательны.
    // Тело можно писать без фигурных скобок, если оно из одной строки,
    // но по стилю Kotlin фигурные скобки предпочтительны всегда.
    if (temperature > 30) {
        println("Жарко")
    } else if (temperature > 20) {
        println("Тепло")
    } else if (temperature > 10) {
        println("Прохладно")
    } else {
        println("Холодно")
    }
    // Вывод: Тепло
}
```

### 2.2. `if` как выражение

Главное отличие от Java: `if` **возвращает значение**, поэтому переменную можно инициализировать прямо результатом:

```kotlin
fun main() {
    val a = 7
    val b = 12

    // Ветка else обязательна, если if используется как выражение.
    val max = if (a > b) a else b
    println("max = $max")   // max = 12

    // Можно использовать блоки { } — тогда значением является
    // последнее выражение в блоке.
    val label = if (a % 2 == 0) {
        println("a чётное")    // побочный эффект разрешён
        "even"                 // ← это значение блока
    } else {
        println("a нечётное")
        "odd"
    }
    println("label = $label")  // label = odd
}
```

> **Важно:** если `if` используется как выражение, ветка `else` **обязательна** — иначе компилятор не сможет вывести тип.

### 2.3. Вложенные `if` и ранние выходы

```kotlin
fun checkAccess(age: Int, hasTicket: Boolean, isBanned: Boolean): String {
    // Ранние выходы (guard clauses) читаются лучше,
    // чем глубокая вложенность.
    if (isBanned) return "Доступ запрещён: бан"
    if (age < 18) return "Доступ запрещён: 18+"
    if (!hasTicket) return "Доступ запрещён: нет билета"
    return "Проходите"
}

fun main() {
    println(checkAccess(20, true, false))   // Проходите
    println(checkAccess(16, true, false))   // Доступ запрещён: 18+
}
```

### 2.4. Логические операторы и «короткое замыкание»

```kotlin
fun main() {
    val user: String? = null
    val isAdmin = false

    // && и || ленивы: правая часть вычисляется только при необходимости.
    val canEdit = user != null && user.length > 3 && (isAdmin || user == "editor")
    println(canEdit)   // false
}
```

**Типичная ошибка новичка:** писать `if (x == true)` или `if (flag == false)`. В Kotlin так не принято — достаточно `if (x)` и `if (!flag)`.

## 3. `when` — множественное ветвление

`when` — это «умный `switch`»: возвращает значение, не требует `break`, поддерживает диапазоны, типы и произвольные условия.

### 3.1. `when` с subject

```kotlin
fun main() {
    val dayOfWeek = 3

    val dayName = when (dayOfWeek) {
        1 -> "Понедельник"
        2 -> "Вторник"
        3 -> "Среда"
        4 -> "Четверг"
        5 -> "Пятница"
        6, 7 -> "Выходной"       // перечисление через запятую
        else -> "Некорректный день"
    }
    println(dayName)   // Среда
}
```

### 3.2. `when` с диапазонами

```kotlin
fun main() {
    val score = 87

    val grade = when (score) {
        in 90..100 -> "A"
        in 80..89  -> "B"
        in 70..79  -> "C"
        in 60..69  -> "D"
        else       -> "F"
    }
    println("Оценка: $grade")   // Оценка: B
}
```

### 3.3. `when` без subject

```kotlin
fun classify(a: Int, b: Int): String = when {
    a > 0 && b > 0 -> "оба положительные"
    a < 0 && b < 0 -> "оба отрицательные"
    a == 0 && b == 0 -> "оба нули"
    else -> "разные знаки"
}
```

### 3.4. `when` с проверкой типа (`is`)

```kotlin
val value: Any // написать = любой тип
val st: String = when (value) {
    is Int    -> "Int: $value"
    is String -> "String длиной ${value.length}"
    is Boolean -> if (value) "Boolean: true" else "Boolean: false"
    null      -> "null"
    else      -> "неизвестный тип"
}
```

> **Замечание:** `is Int` внутри ветки включает **smart cast** — `value` рассматривается как `Int`, доступны его методы.

### 3.5. `when` без `else`

Если `when` используется **как выражение** и покрывает все варианты `else` не нужен:

```kotlin

fun main() {
    val score = 87

    val grade = when (score) {
        in 90..100 -> "A"
        in 80..89  -> "B"
        in 70..79  -> "C"
        in 60..69  -> "D"
        in 0..59   -> "F"
    }
    println(grade)   // Оплачен
}
```

### 3.6. `when` как инструкция

```kotlin
fun main() {
    val code = 404

    // Без присваивания результата — это инструкция.
    when (code) {
        200 -> println("OK")
        301 -> println("Moved Permanently")
        404 -> println("Not Found")
        in 500..599 -> println("Server Error")
        else -> println("Другой код: $code")
    }
}
```

## 4. Элвис `?:` и `when` вместе

```kotlin
fun main() {
    val input: String? = null

    val safeInput = input ?: "нет ввода"
    println(safeInput)   // нет ввода

    // when с локальной переменной — вычисляем один раз, разбираем в ветках.
    val message = when (val s = input) {
        null -> "пусто"
        else -> "введено: $s"              // smart cast: s уже String
    }
    println(message)   // пусто
}
```

## 5. `if` vs `when`: что выбирать

| Ситуация | Выбор |
|---|---|
| Два возможных исхода | `if` |
| Больше двух вариантов по одному значению | `when` |
| Ветки по диапазонам, типам, условиям над разными объектами | `when` без subject |
| Проверка на `null` с действием при ненулевом | `?.let` / `if (x != null)` |
| Значение по умолчанию | `?:` |
| Разбор `sealed class` / `enum` | `when` (проверка на полноту) |

## 6. Полезные идиомы

```kotlin
fun main() {
    // takeIf — вернуть значение только при выполнении условия; иначе null
    val input = "  "
    val valid = input.trim().takeIf { it.isNotEmpty() } ?: "по умолчанию"

    // takeUnless — обратное
    val n = 5
    val notZero = n.takeUnless { it == 0 } ?: -1

    // require / requireNotNull — проверки с понятным сообщением
    // check / checkNotNull — то же, но IllegalStateException
    val name: String? = "Анна"
    val safeName = requireNotNull(name) { "имя обязательно" }

    // coerceAtMost / coerceAtLeast / coerceIn — ограничение значения
    val discount = 35.coerceAtMost(30)   // 30
    println("$valid $notZero $safeName $discount")
}
```

## Итог

Условные конструкции в Kotlin устроены так, чтобы код читался сверху вниз и не требовал «флагов и накопителей». `if` — выражение, `when` — универсальный инструмент для множественного выбора (по значению, диапазону, типу, произвольному условию). Сочетание `when` с `enum`/`sealed class` даёт проверку на полноту на этапе компиляции, а `?:`, `?.let`, `takeIf` закрывают типовые сценарии работы с `null` без `if`. Практическая часть оставлена в виде каркаса: студент сам реализует тела функций, а тесты из примеров ввода/вывода служат готовыми сценариями для проверки.
