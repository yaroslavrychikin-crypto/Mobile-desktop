# Kotlin: переменные, типы, запуск программы, ввод и вывод

## 1. Как запустить Kotlin: три способа

### 1.1. Онлайн-песочница (самый быстрый старт)

Открываете **play.kotlinlang.org** — вставляете код, нажимаете Run. Ничего устанавливать не нужно. Идеально для проверки примеров из этого конспекта.

### 1.2. IntelliJ IDEA (основная среда для JVM-разработки)

1. Устанавливаете **IntelliJ IDEA Community** (бесплатная).
2. `File → New → Project → Kotlin` → выбираете JDK (17+).
3. В `src/main/kotlin` создаёте файл, например `Main.kt`.
4. Пишете `fun main() { ... }` и нажимаете зелёный треугольник слева от `main`.

### 1.3. Командная строка (`kotlinc`)

```bash
# Установка (через SDKMAN, brew или с kotlinlang.org)
sdk install kotlin

# Компиляция и запуск
kotlinc Main.kt -include-runtime -d Main.jar
java -jar Main.jar
```

### 1.4. Android Studio

Для мобильной разработки Kotlin — основной язык. Но для отработки синтаксиса удобнее начинать с IntelliJ или онлайн-песочницы: там быстрее цикл «написал → запустил → увидел результат».

> **Ключевое правило:** любая программа на Kotlin начинается с функции `main()`. Точка входа может быть двух видов:
> ```kotlin
> fun main() { ... }              // без аргументов
> fun main(args: Array<String>) { ... } // с аргументами командной строки
> ```

## 2. Первая программа

```kotlin
// Файл Main.kt
// Строки, начинающиеся с //, — однострочные комментарии.

    // println — вывод строки с переводом на новую строку
```

Запускается без объявления класса, пакета и `public static void`. Компилятор сам находит `main`.

## 3. Переменные: `val` и `var`

В Kotlin переменная объявляется **ключевым словом**, а не типом. Тип идёт после имени через двоеточие (или выводится автоматически).

```kotlin
fun main() {
    // val — неизменяемая ссылка (аналог final в Java).
    // Присвоить второй раз нельзя — компилятор не даст.
    val appName: String = "Shop"
    // appName = "Other"   // ОШИБКА КОМПИЛЯЦИИ: Val cannot be reassigned

    // var — изменяемая переменная
    var counter: Int = 0
    counter = counter + 1   // допустимо
    counter++               // тоже допустимо

    println("appName = $appName, counter = $counter")
    // Вывод: appName = Shop, counter = 1
}
```

**Соглашение:** по умолчанию используйте `val`. Меняйте на `var` только тогда, когда значение действительно должно переприсваиваться. Это снижает количество случайных ошибок.

### 3.1. Вывод типов (type inference)

Тип можно не писать, если компилятор выводит его из инициализатора:

```kotlin
fun main() {
    val age = 25                 // Int
    val height = 1.75            // Double (дробное — всегда Double)
    val initial = 'A'            // Char (одинарные кавычки)
    val active = true            // Boolean
    val message = "Hello"        // String (двойные кавычки)
    val big = 10_000_000_000L    // Long (суффикс L)
    val small: Byte = 42         // Byte — только с явным типом

    println("$age $height $initial $active $message $big $small")
    // Вывод: 25 1.75 A true Hello 10000000000 42
}
```

Тип **фиксируется** при первом присвоении. Нельзя записать в `Int`-переменную строку:

```kotlin
fun main() {
    var x = 10
    // x = "text"   // ОШИБКА КОМПИЛЯЦИИ: Type mismatch
}
```

### 3.2. Инициализация обязательна

В Kotlin переменная не может быть объявлена «в воздухе». Если значение появится позже — используйте `lateinit` (только для `var` и непримитивных типов) или nullable-тип:

```kotlin
fun main() {
    // lateinit var token: String
    // token = "abc"  // инициализация позже
    // println(token)

    var name: String? = null   // nullable, безопаснее
    name = "Кот"
    println(name)              // Кот
}
```

> Для локальных переменных `lateinit` не разрешён — только для свойств класса. В учебных примерах проще сразу использовать nullable или присваивать значение при объявлении.

## 4. Базовые типы

Kotlin — язык со **статической типизацией**. Примитивы представлены классами, но компилятор оптимизирует их до JVM-примитивов.

| Тип | Размер | Диапазон / особенности | Пример |
|---|---|---|---|
| `Byte` | 8 бит | −128…127 | `val b: Byte = 100` |
| `Short` | 16 бит | −32768…32767 | `val s: Short = 30_000` |
| `Int` | 32 бит | ±2.1 млрд (по умолчанию для целых) | `val i = 42` |
| `Long` | 64 бит | ±9.2 · 10¹⁸, суффикс `L` | `val l = 5_000_000_000L` |
| `Float` | 32 бит | ~7 значащих цифр, суффикс `f` | `val f = 1.5f` |
| `Double` | 64 бит | ~15 значащих цифр (по умолчанию) | `val d = 1.5` |
| `Char` | 16 бит | один символ в одинарных кавычках | `val c = 'A'` |
| `Boolean` | — | `true` / `false` | `val ok = true` |
| `String` | — | текст в двойных кавычках | `val s = "Hi"` |
| `Unit` | — | аналог `void` | результат функций без значения |
| `Nothing` | — | «значение, которого нет» (для `throw`) | функция, которая не возвращает |

### 4.1. Числа

```kotlin
fun main() {
    // Десятичные литералы
    val decimal = 42
    val million = 1_000_000        // подчёркивания для читаемости допустимы
    val longValue = 10_000_000_000L // без L компилятор ошибётся: число больше Int

    // Шестнадцатеричные (0x), двоичные (0b), восьмеричные (не поддерживаются)
    val hex = 0xFF                 // 255
    val bin = 0b1010               // 10

    // Дробные
    val pi = 3.14                  // Double
    val half: Float = 0.5f         // Float — обязателен суффикс f

    // Специальные значения Double
    val inf = Double.POSITIVE_INFINITY
    val nan = Double.NaN

    println("$million $longValue $hex $bin $pi $half $inf $nan")
    // Вывод: 1000000 10000000000 255 10 3.14 0.5 Infinity NaN
}
```

### 4.2. Символы и строки

```kotlin
fun main() {
    // Char — один символ, одинарные кавычки
    val letter: Char = 'K'
    val newline = '\n'           // escape-последовательность
    val tab = '\t'
    println("Буква:$tab$letter$newline")  // Буква:   K

    // String — двойные кавычки
    val name = "Анна"

    // Обычная конкатенация
    println("Привет, " + name + "!")

    // Интерполяция шаблонов — $переменная или ${выражение}
    println("Привет, $name!")
    println("Длина имени: ${name.length}")

    // Многострочные raw-строки: тройные кавычки, без escape
    val json = """
        {
          "user": "$name",
          "age": 25
        }
    """.trimIndent()
    println(json)
}
```

> **Подводный камень:** `"${name.length}"` работает, а `"$name.length"` — нет: `$` захватывает только имя переменной, `.length` останется текстом. Если внутри `$` нужно выражение — всегда используйте фигурные скобки.

### 4.3. Boolean и логические операции

```kotlin
fun main() {
    val a = 10
    val b = 3
    val isPositive = a > 0         // true
    val both = isPositive && b > 0 // true (логическое И)
    val either = isPositive || b < 0 // true (логическое ИЛИ)
    val not = !isPositive           // false

    // Сравнения возвращают Boolean
    println(a == b)   // false — сравнение значений
    println(a != b)   // true
    println(a > b)    // true
    println(both && either && !not)  // true
}
```

## 5. Вывод: `print`, `println`, интерполяция

```kotlin
fun main() {
    // print — без перевода строки
    print("A")
    print("B")
    println()          // перевод строки (пустой println)
    // Вывод: AB

    // println — с переводом строки
    println("Первая")
    println("Вторая")
    // Первая
    // Вторая

    // printf-стиль (через метод format у String)
    val price = 1999.999
    println("%.2f руб.".format(price))   // 2000.00 руб.

    // Форматирование целых
    println("%05d".format(42))           // 00042
    println("%x".format(255))            // ff (hex)

    // Шаблоны + вычисления
    val x = 5
    val y = 3
    println("$x + $y = ${x + y}")        // 5 + 3 = 8
}
```

## 6. Ввод: `readln()`, `readLine()`, `Scanner`

Самый современный и безопасный способ в Kotlin — `readln()`. Он **бросает исключение**, если ввода нет, зато не возвращает nullable:

```kotlin
fun main() {
    print("Введите имя: ")
    val name = readln()                 // String, гарантированно не null
    println("Привет, $name!")
}
```

Альтернатива — `readLine()`, возвращает `String?`:

```kotlin
fun main() {
    val line = readLine()
    val safe = line ?: "пусто"
    println("Введено: $safe")
}
```

### 6.1. Чтение чисел (главная ловушка)

`readln()` возвращает **строку**. Для чисел её нужно преобразовать:

```kotlin
fun main() {
    print("Введите первое число: ")
    val a = readln().toInt()

    print("Введите второе число: ")
    val b = readln().toInt()

    println("$a + $b = ${a + b}")
}

// Пример сессии:
// Введите первое число: 5
// Введите второе число: 7
// 5 + 7 = 12
```

Если пользователь введёт не число — вылетит `NumberFormatException`. Безопасный вариант с `toIntOrNull()`:

```kotlin
fun main() {
    print("Введите целое число: ")
    val n = readln().toIntOrNull()
    if (n == null) {
        println("Это не целое число")
    } else {
        println("Квадрат: ${n * n}")
    }
}
```

### 6.2. Чтение нескольких значений из одной строки

Классический приём: `"1 2 3"` → разбить по пробелу и преобразовать:

```kotlin
fun main() {
    print("Введите три числа через пробел: ")
    val parts = readln().split(" ")               // List<String>
    val a = parts[0].toInt()
    val b = parts[1].toInt()
    val c = parts[2].toInt()
    println("Сумма: ${a + b + c}")
}

// Ввод: 10 20 30
// Вывод: Сумма: 60
```

Более гибко — с фильтром пустых токенов на случай двойных пробелов:

```kotlin
fun main() {
    val nums = readln()
        .trim()
        .split(Regex("\\s+"))
        .map { it.toInt() }
    println("Сумма: ${nums.sum()}")
}
```

### 6.3. `java.util.Scanner` (для мобильных/JVM-проектов)

Иногда его удобнее — например, при чтении токенов:

```kotlin
import java.util.Scanner

fun main() {
    val sc = Scanner(System.`in`)
    println("Введите имя и возраст:")
    val name = sc.next()           // одно слово
    val age = sc.nextInt()         // целое число
    println("$name, $age лет")
}
```

## 7. Преобразование типов

Kotlin **не выполняет неявных преобразований** даже между числовыми типами. `Int` в `Long` автоматически не превращается.

```kotlin
fun main() {
    val i: Int = 100
    // val l: Long = i        // ОШИБКА: Type mismatch

    val l: Long = i.toLong()  // явное приведение
    val d: Double = i.toDouble()
    val f: Float = i.toFloat()
    val b: Byte = i.toByte()  // осторожно: 100 влезет, 300 — переполнится

    println("$l $d $f $b")    // 100 100.0 100.0 100

    // Строка ↔ число
    val fromStr = "42".toInt()
    val toStr = 42.toString()
    println("$fromStr $toStr")

    // Осторожно: "42.5".toInt() бросит NumberFormatException
    // Для проверки — *OrNull-варианты:
    val safe = "abc".toIntOrNull()          // null
    println(safe)

    // Дробное → целое (отбрасывание дробной части, не округление!)
    println(3.99.toInt())                   // 3
    println(Math.round(3.99))               // 4 (возвращает Long)
}
```

| Метод | Куда |
|---|---|
| `.toByte()`, `.toShort()` | Byte, Short |
| `.toInt()`, `.toLong()` | Int, Long |
| `.toFloat()`, `.toDouble()` | Float, Double |
| `.toChar()` | Char (по коду) |
| `.toString()` | String |
| `.toIntOrNull()` и др. | число или `null` |

## 8. Константы

`const val` — константа времени компиляции (только для примитивов и `String` на верхнем уровне или в `object`):

```kotlin
const val APP_VERSION = "1.0.0"        // верхний уровень
const val MAX_ITEMS = 100

object Config {
    const val API_URL = "https://api.example.com"
}

fun main() {
    println("Версия $APP_VERSION, максимум $MAX_ITEMS")
    println("API: ${Config.API_URL}")
}
```

Отличие от `val`: `val` вычисляется в момент выполнения, `const val` — в момент компиляции (значение подставляется в байт-код).

## 9. Полезные мелочи, которые часто нужны сразу

```kotlin
fun main() {
    // Диапазоны
    for (i in 1..5) print("$i ")        // 1 2 3 4 5
    println()
    for (i in 1 until 5) print("$i ")   // 1 2 3 4
    println()
    for (i in 5 downTo 1 step 2) print("$i ")  // 5 3 1
    println()

    // Проверка вхождения в диапазон
    val grade = 85
    println(grade in 0..100)            // true

    // Свойства строк
    val s = "  Kotlin  "
    println("'${s.trim()}'")            // 'Kotlin'
    println(s.trim().uppercase())       // KOTLIN
    println(s.trim().reversed())        // niltoK
    println(s.contains("tl"))           // true
}
```

## Задача 8. Конвертер валют с комиссией

**Цель:** закрепить `val`/`var`, `Double`, ввод, преобразование типов, `toDoubleOrNull`, форматирование, `const val`.

**Условие.** Пользователь вводит сумму в рублях и курс доллара (сколько рублей за 1 $). Программа считает сумму в долларах, удерживает фиксированную комиссию 1.5 % и выводит результат с двумя знаками после запятой. Некорректный ввод — понятное сообщение, без падения.


Пример сессии:
``` bash
 Сумма в рублях: 10000
 Курс (руб. за 1 $): 90
 Сумма:       10000.00 ₽
 Комиссия:    150.00 ₽ (1.5 %)
 К получению: 9850.00 ₽
 В долларах:  109.44 $
```

**Разбор подводных камней:**
- `.replace(',', '.')` — на русской раскладке пользователь часто вводит `10000,5`; без замены `toDoubleOrNull()` вернёт `null`.
- `1.5 / 100.0` — если бы написали `15 / 100` в `Int`, получили бы `0`. Здесь всё `Double`, но привычку «делить на `100.0`» стоит вырабатывать сразу.

## Итог

Kotlin убирает многословность Java, но сохраняет строгую типизацию: компилятор знает тип каждой переменной и не позволит случайно положить строку в число. На старте важно запомнить три вещи: **(1)** `val` по умолчанию, `var` — только для реально изменяемых значений; **(2)** `readln()` возвращает строку, числа получаем через `toInt()` / `toIntOrNull()`; **(3)** интерполяция `"$x"` и `"${выражение}"` — основной способ собирать вывод, который не засоряет код конкатенацией. Этого достаточно, чтобы писать первые консольные программы и переходить к функциям, условиям и коллекциям — следующим темам курса.
